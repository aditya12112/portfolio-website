# Aditya Raj — Portfolio Website

A clean, responsive, and interactive personal portfolio website showcasing projects, technical skills, academic background, and internship experience in Computer Science, Artificial Intelligence, and Machine Learning.

## 🚀 Features

- **Modern & Responsive UI**: Sleek dark mode design styled with Space Grotesk and Inter typography.
- **Interactive Neural Network Canvas**: Crisp particle and node network animated with Retina / high-DPI scaling and battery-saving offscreen pause.
- **Projects Showcase**: Highlights machine learning models, full-stack applications, and real-world tools with technology stack tags.
- **Smooth Navigation & Scroll-Spy**: Sticky header, scroll progress bar, side dot indicator, and smooth section scrolling.
- **One-Click Contact & Copy**: Direct email and profile links with visual clipboard copy feedback.
- **Accessible & SEO-Ready**: Clean semantic HTML5, Open Graph & Twitter Cards metadata, embedded SVG favicon, and full keyboard/screen-reader accessibility.

## 🛠️ Built With

- **HTML5 & CSS3** (Custom Properties, Grid & Flexbox)
- **Vanilla JavaScript** (IntersectionObserver API, Canvas API, Clipboard API)
- **Google Fonts** (Space Grotesk, Inter)

## 🌐 Live Preview

To view locally, open `index.html` in any modern web browser or serve with a local web server:

```bash
# Using Python
python -m http.server 8000
```
Then visit `http://localhost:8000`.
